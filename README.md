# Haru's Umbrel Community App Store

> [!NOTE]
> Haru's Umbrel Community App Store — personal community app store, not supported for public use.

This repository is a personal community app store for [umbrelOS](https://umbrel.com).

## Included Apps

- **Recyclarr (`haru-recyclarr`)**: Automatically synchronizes TRaSH Guides quality profiles, custom formats, and media naming conventions to Sonarr and Radarr.

## Adding to Umbrel

To install apps from this community store on your Umbrel server:

1. Open your Umbrel web dashboard (`http://umbrel.local`).
2. Navigate to **App Store**.
3. Click the three dots menu (**⋮**) in the top right corner.
4. Select **Community App Stores**.
5. Paste the GitHub repository URL:
   ```
   https://github.com/iamdavecalleja/haru-umbrel-app-store
   ```
6. Click **Add**. The store and its apps will appear in your App Store catalog.
